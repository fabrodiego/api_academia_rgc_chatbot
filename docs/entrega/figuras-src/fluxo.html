Fluxo completo do chatbot RGC

Cada mensagem passa por 3 etapas próprias (sem serviço de PLN pronto) até virar resposta ou encaminhamento
Caminho de uma mensagem

Entrada

Usuário no site (widget) ou na /demo.html

POST /api/chat

Spring Boot 3 · Java 17

➜

1Pré-processamento

  • minúsculas, sem acento e pontuação
  • remove stopwords
  • negação: nao_quero
  • "aí" vira e_ai só após cumprimento
➜

2TF-IDF + cosseno

  • vetor TF-IDF da mensagem
  • cosseno com as 1.410 frases de treino
  • score da intent = melhor frase
  • top-3, margem e % de palavras conhecidas
➜

3Regras de decisão

  • palavras conhecidas < mínimo → encaminha
  • score < 0,18 → encaminha
  • margem < 0,02 → contexto desempata
  • margem < mínima → encaminha
  • senão → responde a 1ª intent
➜

Responde

texto da intent em bot_responses

Encaminha

atendimento humano (recepção / WhatsApp)

Componentes de apoio

Base de conhecimento

Postgres: 49 intents, 97 respostas, 1.410 frases; carregada em memória

Contexto da sessão

última intent por sessionId, 30 min; usado só no desempate

Log de conversas

toda interação vai para conversations

Feedback humano

frase só vira treino depois que a equipe confirma a intent

Exemplo real (produção)
"Qual o valor do plano mensal?" ➜ valor plano mensal ➜ plano_mensal 1,00 · planos_valores 0,70 · plano_anual 0,68 ➜ passou nas regras ➜ responde plano_mensal (7 ms)
